 Mission: Python 가상 환경 구축 및 GitHub 저장소 연동
1. 한 일 (What I did)
가상 환경(.venv) 생성 및 활성화: 터미널에서 python -m venv .venv 명령어를 사용해 프로젝트 전용 가상 환경을 만들고, source .venv/Scripts/activate로 활성화함.

패키지 설치: requests 패키지를 가상 환경 내에 설치함.

VS Code 환경 설정: 명령 팔레트(Ctrl+Shift+P)를 통해 Python 인터프리터를 프로젝트 내 .venv로 지정함.

GitHub 저장소 연동 확인: git remote -v 및 git branch -a 명령어로 원격 저장소(origin)와 main 브랜치 연결 상태를 확인함.

보안 및 예외 처리 설정: .gitignore 파일을 생성하고 .env, .venv/, __pycache__/를 추가하여 민감한 정보와 불필요한 대용량 파일이 Git에 기록되지 않도록 설정함.

2. 확인한 결과 (Results)
터미널에 (.venv)가 표시되고, python -c "import sys; print(sys.executable)" 실행 시 출력 경로에 .venv가 포함된 것을 확인함. (가상 환경 정상 작동)

VS Code에서 requests 모듈의 노란색 경고 줄(Import 에러)이 사라짐. (인터프리터 정상 연결)

git remote -v 결과, https://github.com/subinhappy777-hub/security-agent-toolkit.git 주소로 fetch/push가 정상 연결되어 있음을 확인함.

git ls-files | grep -E "\.env|\.venv" 실행 결과 TRACKING_CLEAN이 출력되어, 민감 파일이 Git 추적 목록에 없음을 확인함.

3. 새로 알게 된 점 (What I learned)
터미널 명령어의 띄어쓰기 중요성: python -c를 python-c로 입력하면 명령어를 찾지 못해 command not found 에러가 발생한다는 것을 배움.

Python 모듈의 정확한 속성명: sys.executable을 sys.excutable로 오타를 내면 AttributeError가 발생하며, 파이썬이 친절하게 올바른 철자(.executable)를 제안해 준다는 것을 알게 됨.

패키지 이름의 정확성: requests(복수)를 request(단수)로 설치하려 하면 PyPI에서 찾을 수 없다는 에러가 발생함을 확인함.

Git Bash의 가상 환경 활성화 경로: Windows 환경의 Git Bash에서는 Scripts/activate를 사용해야 하며, bin/activate(Mac/Linux용)와 다르다는 점을 명확히 이해함.

Git의 빈 폴더 처리: Git은 빈 폴더 자체를 기록하지 않으므로, docs 폴더 등을 업로드하려면 그 안에 반드시 파일(예: .md)이 있어야 한다는 것을 배움.

.gitignore의 역할과 캐시 삭제: .gitignore는 앞으로의 추적만 막아주므로, 이미 올라간 파일은 git rm -r --cached 명령어로 Git의 기억(캐시)에서 지워야 한다는 원리를 이해함.

내가 몰랐던 점

".gitignore에 .env, .venv/, pycache/를 넣습니다." (보안 및 용량 관리)

의미: GitHub에 올리면 안 되는 파일들을 .gitignore에 명시하라는 것입니다.

    .env: 비밀번호, API 키 등이 들어있는 민감한 파일 (절대 올리면 안 됨)

    .venv/: 가상 환경 폴더 (용량이 크고, 컴퓨터마다 다르므로 올릴 필요 없음)

    __pycache__/: Python이 코드를 실행할 때 자동으로 만드는 임시 캐시 폴더 (올릴 필요 없음)

코드: printf ".env\n.venv/\n__pycache__/\n" >> .gitignore

*.gitignore는 "앞으로 올라갈 파일"만 막아줍니다. 
  만약 이전에 실수로 .env나 .venv를 git add 해서 이미 Git이 기억하고 있다면, .gitignore에 추가해도 계속 추적합니다.
  이럴 때는 Git의 기억(캐시)에서 지워주는 명령어를 실행해야 합니다. 
   코드: git rm -r --cached .env .venv __pycache__
