## 오늘 새로 쓴 명령

git init -b main	이 폴더를 git 폴더로 만들기 (브랜치 main)	.git 폴더 생성
git remote add origin <주소>	깃허브 주소를 origin으로 등록	없음
git fetch origin	깃허브 기록을 받아 오기만	없음 (파일 그대로)
git reset origin/main	기록 위치를 origin/main에 맞춤	없음 (옵션 없을 때)
git branch -u origin/main	main의 짝을 origin/main으로 지정	없음
git status	현재 상태 확인	없음 (읽기만)

## 찾아보고 알게 된 것
- 저장소와 내 폴더는: 깃허브(원격)와 PC(로컬)에 각각 존재하는 두 사본이고,
  git이 둘의 기록을 맞춰 준다. clone 없이도 기존 폴더를 init+remote add+fetch+reset으로 연결할 수 있다.

- fetch는 가져오기만, reset(옵션 없이)은 기록 위치만 옮기고 내 파일은 그대로.
- --hard를 붙이면 내 파일이 덮어써지므로 위험.
